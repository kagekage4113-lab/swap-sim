# スワップ複利シミュレーター

外貨スワップポイントを再投資してロットを増やしていく運用を、ブラウザ上でシミュレーションするツールです。
スマホのホーム画面に追加すれば、アプリのように使えます(PWA対応)。

**デモ:** https://kagekage4113-lab.github.io/swap-sim/

## できること

条件を入力すると、次の4つの推移をグラフと表で確認できます。

1. ロット数 / 日次スワップ
2. 純資産
3. 現在レート と デッドラインレート(維持率100%になるレート)
4. 維持率

レートのシナリオは「下落 / 維持 / 上昇」から選べます。期間終了時点までの変化率を指定すると、レートは直線的に推移します。

## 入力項目

| 項目 | 内容 |
| --- | --- |
| 現在のロット数 | 1Lot = 10,000通貨 |
| 現在のレート | 保有通貨の現在レート |
| 現在の純資産 | 証券口座の「証拠金評価額」(円) |
| 毎月の積立額 | 30日ごとに追加入金する額 |
| 買い増し目標維持率 | 買い増したロットが、この維持率になるように買い増す |
| 再投資トリガー額 | スワップがこの額に達するたびに買い増す |
| 1Lotあたりの日次スワップ | 円/日 |
| レートシナリオ・期間 | 下落/維持/上昇と変化率、1〜60ヶ月 |

## 計算の前提

- 必要証拠金率は4%(レバレッジ25倍)で固定
- 1ヶ月 = 30日として計算
- 日次スワップは一定(スワップの変動、スプレッド、税金は考慮しません)
- 毎日スワップを積み立て、トリガー額に達したら、その額を証拠金として目標維持率で買い増し
- デッドラインレート = 維持率が100%になるレート(ロスカット水準の目安)

実際のロスカット基準は、各証券会社の規定をご確認ください。

## 使い方(ローカル)

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで動きます。
グラフ描画にChart.jsをCDNから読み込むため、初回はネット接続が必要です。
